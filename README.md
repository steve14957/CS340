1. How do you write programs that are maintainable, readable, and adaptable?

     Throughout this course, I learned the importance of writing code that is organized, readable, and reusable.  One of the most valuable experiences was developing the Python CRUD module in Project One and then using that
same module in Project Two to connect the Grazioso Salvare dashboard to the MongoDB database.  By separating the database operations from the dashboard interface, I was able to keep the code more organized and make changes
to individual components without affecting the entire application.

     One of the biggest advantages of this approach was reusability.  Instead of writing new database connection and query code for each dashboard feature, I could use the existing CRUD module to retrieve the information
needed for the interactive data table, charts, and map.  This made the development process more efficient and reduced unnecessary duplication.  In the future, I could reuse or expand this module for other applications that
require database connectivity.  This project demonstrated how modular programming makes software easier to maintain, troubleshoot, and adapt to changing requirements.

3. How do you approach a problem as a computer scientist?

     My approach to solving problems as a computer scientist involves understanding the requirements, breaking the problem into smaller tasks, and testing each component as it is developed.  For the Grazioso Salvare project,
I first needed to understand how the organization wanted to identify and select rescue animals based on specific training requirements.  This meant working with the MongoDB database to retrieve animal records and developing
filters that allowed users to narrow the results based on different rescue categories.

     This project was different from many of my previous programming assignments because it required several technologies to work together.  I had to connect a database to a Python application, create an interactive dashboard
using Dash, display information through a data table and pie chart, and incorporate a map that updated based on the selected animal.  Each feature presented different challenges, and I worked through them by making
incremental changes, testing the results, and troubleshooting problems as they occurred.

     One of the most important lessons I learned was the value of building software in stages.  Rather than trying to implement every dashboard feature at once, I focused on getting the database connection and data retrieval
working before adding the visual components.  In future projects, I plan to continue using this approach while placing even greater emphasis on understanding client requirements, organizing code into reusable components, and
testing throughout development.

3. What do computer scientists do, and why does it matter?

     Computer scientists design, develop, and maintain technology that helps individuals and organizations solve problems more efficiently.  Their work involves more than writing code.  It requires understanding what users
need, analyzing information, designing appropriate solutions, and ensuring that software functions reliably.  This course helped me better understand how computer science can be applied to real-world business and
organizational needs.

     The Grazioso Salvare dashboard is a good example of how software can improve an organization's daily operations.  By providing an interactive interface connected to a database, the dashboard allows users to search and
filter animal records, examine breed information through a chart, and view animal locations on a map.  Instead of manually searching through large amounts of data, the organization can use these tools to identify animals that
may be suitable for specific rescue training programs.  This can save time, improve decision-making, and allow employees to focus more attention on their primary responsibilities.

     As I continue working toward my bachelor's degree in computer science and developing my own software and web development business, I can see how these skills will apply to future client projects.  Businesses often need
applications that organize information, automate processes, and make data easier to understand.  This course gave me practical experience developing a database-driven application and reinforced the importance of creating
software that addresses real problems and provides meaningful value to its users.
